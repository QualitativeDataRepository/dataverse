Dataverse now fully supports use of the Local Contexts v2 API when using the [Local Contexts Integration mechanism](https://guides.dataverse.org/en/latest/installation/localcontexts.html).The involved external vocabulary mechanism in Dataverse now supports the use of the dataset id or PID in the "retrieval-uri" configuration setting, which is a general capability for [external vocabulary script](https://github.com/gdcc/dataverse-external-vocab-support) developers.
